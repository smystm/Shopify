# Weapon skins

Each subfolder matches a weapon filename from the parent `weapons-real`
folder. It contains every unique skin entry available in the public CS2 skin
catalog used for these Steam CDN renders.

- 34 weapon folders
- 1,449 transparent PNG skin renders
- `manifest.json` maps each image to its skin name, catalog ID, and source URL
- Images are sized with Steam's `360fx360f` render variant
