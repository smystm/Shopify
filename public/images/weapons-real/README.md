# Realistic CS weapon renders

This folder contains one transparent PNG render for every weapon that exists in
`../weapons`. The filenames intentionally match the original SVG filenames so
the two asset sets can be swapped without changing weapon data.

The renders were downloaded from Steam's public Counter-Strike 2 Community
Market image CDN. They use representative in-game skins to provide the proper
weapon shape, colors, and visual detail.
